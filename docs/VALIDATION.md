浏览器测试用 FFmpeg 合成 H.264/AAC HLS，验证真实播放时间推进、360p 与 720p 的实际解码尺寸切换、关闭后媒体/网络资源清理及重开。网络失败测试单独返回 503，并验证错误提示与官网回退入口。其他检查覆盖搜索、分类、收藏持久化、自定义频道安全校验/增删、键盘焦点、官方来源及安装清单。

新增导入测试覆盖分组持久化、重复/危险 URL、选择导入、本地 M3U、HLS 清单识别、TVBox 相对引用、插件零请求、GitHub Raw 转换、读取失败、过期预览、关闭请求竞态和手机布局。真实 `qist/tvbox/list.txt` 的文本通过解析器及浏览器粘贴预览验证，共 202 条；此检查未播放媒体。

播放器库按需加载：首屏应用 JavaScript 约 18.53 KB gzip，HLS 额外约 178.98 KB gzip，仅打开应用内直播时下载。构建器对 HLS 分块大于 500 KB（压缩前）给出体积提示；该分块已通过动态导入与首屏拆分。

回归时发现长期运行的开发服务在依赖重装后返回 `504 Outdated Optimize Dep`，导致三项播放检查失败。重启本次开发服务并使用 `--force` 重建 Vite 依赖缓存后，完整 20 项浏览器测试通过；未削弱测试断言或更改播放器逻辑。
