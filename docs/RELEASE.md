# 映界 AURA TV · 公开预览版

Windows 优先的轻量电视 PWA：中文深色界面、频道搜索与收藏、键盘浏览、全屏、按片源切换清晰度，以及 M3U/TXT/TVBox 静态频道列表导入。

## Windows 使用

1. 下载 `aura-tv-windows.zip` 并解压。
2. 安装 Node.js 24 LTS 后双击 `start-windows.cmd`。
3. 在 Edge 或 Chrome 中通过浏览器安装功能获得独立窗口。使用本地版本时保持启动窗口运行。

该下载包包含源码、构建产物和启动脚本，不是原生 `.exe` 安装器。`SHA256SUMS` 提供下载完整性校验。

## 验证与限制

发布流水线执行 TypeScript/生产构建、24 项单元测试、20 项浏览器测试，以及根路径和 GitHub Pages 子路径的生产/PWA验证。浏览器播放测试使用本地合成的 HLS 媒体验证解码、360p/720p 切换和资源清理。

央视、CNN、NASA+ 使用官方观看入口；CNN 完整直播可能需要订阅。内置和导入的公网候选片源受地区、源站与浏览器策略影响，尚未完成全部实播验证。公开收录不代表内容授权。

Windows 启动脚本尚未在真实 Windows 系统上实测，因此本版以预览版发布。
